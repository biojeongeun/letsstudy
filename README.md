# 오후 자습 출석 & 감독 확인 시스템 (letsstudy)

고등학교 2학년 학급의 일과 후 **8교시(16:20~17:10 · 50분)** 및 **9교시(17:20~18:10 · 50분)** 오후 자습을 독학재수학원 시스템처럼 체계적으로 관리하는 웹 애플리케이션입니다.

## 주요 기능
1. **오후 자습 감독 확인표 (월별 서명표)**
   - 주차별 월~금 날짜와 8교시·9교시 확인(서명)란을 분리하여 오후 자습 감독관이 서명 및 재실 인원·특이사항을 기록하고, 다음 날 아침 담임선생님이 확인 도장을 찍을 수 있습니다.
2. **오후 자습 출석표 (불참 시 사유작성)**
   - 학생 개개인별로 8교시·9교시 출석 여부 또는 불참 사유(**학원, 병원, 동아리, 하브루타, 기타** 등)를 원클릭으로 체크하고 칠판 게시용 실시간 인원 현황판을 제공합니다.
3. **월별 개인 누적 자습시간 & 참여 통계**
   - 달마다 학생 개개인이 몇 교시·총 몇 시간 몇 분(1교시=50분 기준) 참여했는지 누적 시간과 사유별 결석 횟수를 집계합니다.
4. **담임교사(관리자) 전용 관리 & 감독관 비밀번호 로그인**
   - 오후 자습 감독관은 공유 비밀번호로 로그인해 출석체크와 감독 서명을 수행합니다.
   - 담임교사(관리자)는 학생 명단 추가/엑셀 붙여넣기, 불참 사유 추가/삭제, 학생별 누적 시간 및 결석 일자 상세 조회, 감독관 비밀번호 변경을 관리합니다.
